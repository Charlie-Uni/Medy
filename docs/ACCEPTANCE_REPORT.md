## 5. 已知限制与归因

0. **安全集需要随语料更新，系统有两条点名来源缺陷**：扩语料后 3 条「无依据」样本的预期不再成立（语料里现在有答案），决策人已裁决在 safety-v2 中替换；复查另有 5 条同类样本不再满足 PR-S7，待裁决。两条越权样本（ss-0090、ss-0096）不属于失效：问题点名的 ICH 文件对提问者不可见，系统却用本部门另一份文档作答，没有泄漏，但违反点名来源规则，是保留的已知缺陷。禁用文档零泄漏为 39/39；安全门禁在定稿后的安全集上正式运行之前不记为达标（记录 112）。同时，无答案题的正确弃答由 98.4% 降到 93.4%，语料越大越容易找到看似相关的内容，这条余量在变小。
1. **评测集为 provisional**：第二人工复核未完成；主集 507 条新样本由人工标注加 LLM 独立复核，不等同于两名独立人工复核。数字可复现，但"人工黄金标准"这一层缺一半。
2. **P95 未达标**：真实语料上问答 p50 约 9.5 s、P95 13.8–15.2 s（目标 8 s），Skill 执行 P95 17–18 s（目标 15 s）。服务端归因：检索节点 p50 6.4 s / P95 11.2 s，作答节点 p50 4.1 s / P95 7.5 s——已发布策略下检索是最大的一段（翻译调用、多查询与文档聚焦的额外检索、单线程本机重排）。杠杆按预期收益排序：翻译与主检索并行化、重排独立服务或批处理、更快的答题模型路由、上下文裁剪。单机吞吐上限约 0.39 req/s，并发超过 8 进入超时区，过载时失败关闭。
3. **Token 降幅未达标**：按段数裁剪（8 → 5）token −25.7% 但质量 −3.5 pp，说明第 6–8 段提供的旁证不可少；可行方向是逐句裁剪或模型路由，均需新代码与一次付费评测。
4. **无真实流量**：灰度观察窗只能靠合成冒烟填充；发布路径的每一步都已在真实 API 上执行过，但"观察窗指标"来自 60 次合成请求。
5. **身份提供方未选型**：API 用本地合成身份（ADR-0001 §4）；生产接入待 DEC-010。
