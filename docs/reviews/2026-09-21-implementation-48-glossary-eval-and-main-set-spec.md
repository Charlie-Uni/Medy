## 1. 术语表改写离线评测（INV-EVAL-02）

- 设置：探针 v2 107 条、`medops_v2@5432`、词法 A2、K=20、`as_of=2026-09-20`；三种查询：基线（原查询）、改写并集（原查询 + 实体 + 术语同义词三条查询各取 top-20 后 RRF k=60 融合）、仅术语查询（追加同义词的那一条）；术语表 `glossary-20260920-f569611ab3dd`（67/107 条查询得到追加）。
- 结果（严格宏平均 Recall@20）：

| 配置 | 全部 | 语言一致 | 跨语言 |
| --- | ---: | ---: | ---: |
| 基线 A2 | 58.9% | 77.3% | 15.6% |
| 改写并集 RRF | 57.9% | 76.0% | 15.6% |
| 仅术语查询 | 57.0% | 74.7% | 15.6% |
