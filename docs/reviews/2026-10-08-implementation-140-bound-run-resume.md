# 记录 140：主集/安全集续跑身份、费用与发布提示

日期：2026-10-08。OPT-12/15。本轮自审通过，正式评测及独立复核仍 pending。

## 问题及修复

数据集哈希和 scoring 版本已绑定，但主集/安全运行此前可以在换日期、模型策略、映射或语料后继续往同一目录追加。安全集草案续跑还只比较 query，expected 改了而 query 没变时可能沿用旧判词。另有两个问题：最终汇总只累计各题最后保留的一行，重试前失败费用消失；安全运行在 GPU stalled 时先退出，已完成的尝试行可能未保存。

新 `eval-run-conditions-v1` 固定：

- 实际未提交源码、资源、Schema、依赖锁及当前 runner 的文件摘要；Python/平台和关键已安装依赖版本。
- 样本完整内容哈希及执行顺序、数据集哈希、主集映射文件哈希、评分口径。
- 日期、device、GPU timeout、预算配置、模型/检索/Skill/策略版本、实际发布策略 diff 和实际作答提示摘要。
- 实际数据库身份、source_objects/documents/chunks/chunk_spans/document_acl 及语义索引元数据的逐行摘要。

`run_conditions.json` 保存完整条件及自身 SHA-256；每条尝试有独立 attempt_id 与条件哈希。续跑校验全部尝试，不仅最后一行。身份混用、重复 attempt、无绑定旧行、无效费用字段或条件变化会在第一条新生成前拒绝，原文件保留。空计划和重复样本拒绝；安全选择中的未知 ID/类别拒绝。

事实摘要通过只读 REPEATABLE READ 事务流式计算，不把正文写到结果目录。索引 built_at/built_by/chunk_count/framework 属维护或单独环境信息，排除在事实摘要之外，避免只补 ACK 就被误判为换语料。

## 自审发现的发布提示缺口

主集与安全工具的 `--released` 原本接入了检索参数和模型路由，却漏传 `released.answer_system(...)`。现在两者实际使用发布提示，条件文件记录实际提示 SHA-256 和完整策略 diff 摘要。

真实只读检查发现，本机当前 released 仅含 `retrieval_params/hybrid`，没有 `prompt/answer_system`。因此这次发现是一个已修复的潜在测量差异，不能直接推导“以前全部成绩无效”。历史运行按各自当时发布内容判断。

## 费用口径

质量指标仍按每题最终保留结果统计。`attempt_accounting` 和总费用/调用数统计该目录全部已记录尝试，失败被成功覆盖后费用仍在；最终行费用单列 `retained_outcome_cost_usd`。安全 GPU-stall 先保存行、flush，再退出。

这些数仍不是供应商账单全量证明。若进程在拿到收费结果后、保存尝试前崩溃，可能存在未知收费，记录中明确要求对账；本轮没有宣称进程内 monthly ledger 已变成跨进程月账本。

## 验证

- 新增 **30 项**测试：23 项条件/尝试测试、5 项真实数据库事实摘要测试、2 项真实 runner 控制流测试。控制流测试用明确的合成适配器，不调用外部模型。
- 合成主集连续两次执行：第一次 system_failure 费用 0.1、第二次正确弃答费用 0.2，最终一题总费用 0.3、保留结果费用 0.2；两次均实际收到合成发布提示。改 as_of 续跑被拒，行文件不变。
- 合成安全运行发生 GPU stalled，失败行及费用已保留，两个事实平面的 deps 都接到发布提示。
- 真实数据库测试证明 ACL 和索引版本变化改变对应摘要；单纯 outbox ACK 和 build 记账变化不改变摘要；普通 RLS 身份与非只读/非一致性事务拒绝全局摘要。
- 两个正式库分别在独立连接连续计算两次，摘要相同。两次合计耗时：medops_v2 2.337 秒，medops_v2_safety 2.575 秒；不计入请求时延成绩。见[实际摘要记录](2026-10-08-implementation-140-live-fact-snapshots.json)。

## 限制与下一步

绑定整个 src 包较保守，无关模块改动也可能要求新目录；这是当前可解释的实现，不尝试推断所有动态 import 的语义影响。条件在开始/续跑时采集，不冻结整个实验期间的数据库，不重算二进制向量摘要，也不保证供应商同名模型权重不变。

本轮严格续跑绑定接入主集和安全 runner；回放两臂、基线复用及更强的中途变化检测尚未接入。Plane 的事实快照为这些路径准备了材料，但不能把准备材料记为绑定已完成。
