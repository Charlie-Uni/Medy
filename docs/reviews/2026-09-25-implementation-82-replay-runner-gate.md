## 1. 决定与依据

| 决定 | 依据 |
| --- | --- |
| 门禁是纯函数 `compute_gate()`：输入两臂各 N 次运行的「每项成功 0/1」，输出目标差（pp，点估计）+ 配对 bootstrap 95% CI（2000 次重采样、固定种子）、每个非目标切片的差（部门 / 类型 / 语言 / 命名切片，< 30 项标 `diagnostic_only` 不拦截）、安全按类别取**各臂三次中最差**比较、可靠性（≥ 3 次运行、≥ 200 项）。拦截只看点估计：目标 ≥ +5 pp，非目标下降 ≤ 1 pp，安全不降，安全集必须跑全 | 基线 5.8 逐条；CI 如实报告、不参与阈值（「不事后改阈值」）；同一函数被运行器、发布路由与单元测试共用，避免三处口径 |
| 发布路由不再接受 `{"gate": {"passed": true}}` 这种占位：`gate_report_valid()` 要求完整报告结构、`passed`、冻结回放集哈希、安全跑全、可靠性达标 | 记录 75 的 `gate_passed` 是 M3 占位；M4-08 要求「自动门禁强制」——强制点就是发布 |
| 运行器两臂同项配对：`baseline` = 生产今天应用的 released 指针叠在常量上；`candidate` = baseline + 候选 diff（只限运行时能应用的目标）；N 次独立运行，随机性来自模型；主集项按回放集的标签规则判成败，安全项复用安全运行器的逐项检查（`run_sample` + `judge`，`Plane` 新增 `config` / `answer_system` 叠加参数） | M4-07「3 次独立运行、配对比较」；复用而不是重写检查，安全口径与 M2-15 完全一致 |
| 每次运行都有费用上限（`--max-cost-usd`）、`--estimate` 预算预览、`--resume`（按臂 / 轮 / 项续跑，`system_failure` 行重做）、`--items N` 冒烟 | 记录 74 C 的预算分级；记录 77 / 78 的经验：长运行会被中断 |
| 报告含每臂每轮的成功率、安全通过率、p50 / p95 时延、token、费用、system_failure 数，以及门禁全文；`results.json.gate` 就是候选 `evidence.gate` 该放的内容 | M4-07「报告目标 / 非目标 / 安全 / 延迟 / Token / 成本」 |
| 首个示例候选 `evals/replay/candidates/2026-09-25-hybrid-rrf40.json`（RRF k 60 → 40）：只用于演练运行器；真实候选的 evidence 必须列 case id | 通道 k 与融合上限已在基线上限 20，rrf_k 是不换模型时唯一可动的检索参数（记录 80 §1） |

## 2. 冒烟运行（真实组件，小规模）

`evals/harness/runs/2026-09-25-replay-smoke-v1`：子集前 4 个主集项（MA，answerable）+ 前 4 个安全项（high_risk），3 轮 × 2 臂，示例候选 rrf_k 60 → 40，费用 0.13 美元（估算 0.27）。
