## 2. 关键边界

### 2.1 不把崩溃当作新执行

原run/attempt/trace/decision/call标识不变；领取新租约代数不是新预算。原根退出永久冻结；没有未结算回执不能清零。决定已消耗但证明尚无调用准入时，可发送原请求的**第一次**调用；已确认回复直接复用。未知在途或已调用但无完整工具观察，停止而不自动补跑。旧持有者迟到仅能追加财务事实，不能推进原head。

### 2.2 不承诺外部exactly-once

提交成功但确认丢失会留保守预留；供应商未确认的请求无法通过本地猜测证明没执行。这种情况下拒绝重复调用。账目与保留事件可继续核对，不因此开放执行权限。

### 2.3 终检预留的推导与真实限制

工程包络是可信服务的显式输入，没有生产默认值。使用真实请求的固定提示/Schema/framing、输出上限和最大user字节数推导；引用部分乘原幂等重试上界。若空草稿的原叙述/要求已超过包络，或推导额度超过原profile，启动前拒绝。最终实际草稿/引用计划超包络也拒绝，不自动缩小必需证据、不扩额度。

共用终检覆盖结构、精确叙述引用、安全、原引用核验、模型叙述语义/完整性/范围判断。内部证明不是completed。恢复closed最终阶段只交接已保存finish申请；不能重开终检。真实语义正确率和实际完成率仍需获准试跑，不由本轮fake provider测试推出。

### 2.4 私有格式与授权

私有LoopState升级v2，强制保存终态原准入预算，防止终检扣费后改写原准入历史；旧v1拒绝，不静默补字段。此前没有部署正式持久Driver。公开36个Schema、冻结数据/gold、默认模型、原ACL表与门禁不变；0029仅新增自身表/角色最小权限和部门强制RLS。正文沿用envelope加密，普通遥测不增加正文。完整保留/轮换调度仍按AGENT-06推进。
