## 3. 解读

1. **小模型在这套任务上明显更差**，而且差在最「简单」的那类：仿單查询（label_query）掉了 18 个百分点。记录 91 的设想——简单意图交给小模型——被数据否定：这类问题的失败不是因为推理复杂，而是从中文仿單里精确抄出剂量、禁忌等数字时小模型更容易引错段落或弃答。
2. **时延没有收益**：候选的 p50 反而高 1.9 s（单轮、不同时段，噪声大，但至少没有看到预期中的变快）。
3. **费用收益是真的**（−72.6%），但按现行规则，质量下降 7 pp 不能用费用抵。保守候选（仅 label_query → luna）按本轮数据会更糟，不再试跑。
