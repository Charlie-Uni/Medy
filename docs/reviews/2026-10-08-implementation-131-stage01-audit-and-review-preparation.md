## 2. 自审发现与修复

1. **部分 key 缺少主语/对象。** ms-0124/0125 的分级原则、ms-0243/0244 的报告原则原短 key 太泛；v2 扩为带明确对象的原文锚点，仍落原 chunk。原页坐标、映射和全部依赖 hash 重算。语义复核仍待实际检查者确认。
2. **草案检查缺少全量约束。** 新增投影分布、同文档上限、规范化 query 唯一性、query/key 重合、新 ID 冲突、PII 和必需文件 hash 检查。v1 仍能复现 long_context=19 的已知缺口；v2 满足现行配额。
3. **家族清单首次生成遇到 `KeyError`。** 不能假定 corpus 中每份文件均已入库；改为显式记录 `not_present_in_db`。三份文件的原拒绝原因分别是 PDF Launch、JavaScript、嵌入文件，见记录 98，不能冒称索引丢失。
4. **数据库 family_id 不等于盲测隔离单元。** 258 份 active 文档没有显式家族暴露引用，但这不证明未见；ICH 不同修订、FDA 转载和同成分不同品牌有跨 family 关系。准备清单将相关性审核和盲测资格保留 pending/null，不把旧题改名充当独立验证。

新页的 7 个 chunk 与本地 norm-v1 页及数据库逐项核对。记录 130 已检查的九份相关文档与 1,445 个 chunk 的证据继续保留。本轮数据库均为只读，未变更来源许可、生产语料或策略。
