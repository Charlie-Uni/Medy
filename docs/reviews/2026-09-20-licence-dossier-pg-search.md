## 2. 需要审核结论的问题

1. AGPL-3.0 第 13 条（网络交互）是否因内部员工通过网络使用本系统而对 pg_search 产生源码提供义务；在未修改、仅安装官方发布包的情况下，该义务的范围是什么。
2. 本仓库代码是否会被认定为 pg_search 的衍生作品（通过 SQL 接口调用、独立进程）；若不构成衍生作品，本仓库的许可证选择不受影响的依据。
3. 若采用商业许可，覆盖范围（部署实例数、内部使用、后续版本）与成本。
4. 嵌入词典与 tantivy-jieba 的许可证是否已在传递依赖清单中逐项确认。
5. 组织内部对 AGPL 组件是否有一律禁止或需特批的政策。

## 4. 可能的结论形式

- 书面批准：给出适用范围与条件，ADR-0002 记录后 C 的 `release_blocked` 可改为 `eligible`。
- 商业许可：签署后同上。
- 不批准：C 只能继续作为实验对照，不进入生产；DEC-001 在 A/B 族内决定。
