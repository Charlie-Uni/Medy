# ADR-0008：DEC-005 初始医学术语表来源与版本更新

- 日期：2026-09-20
- 状态：已决（决策人 2026-09-20 授权实施方决定；可随时否决）
- 决策来源：[实现记录 41](../reviews/2026-09-20-implementation-41-delegated-decisions.md)；基线 INV-HAR-05、5.2、检查项"建立医学术语表及版本；记录通用名、商品名、缩写的来源"

## 决策

1. **结构**：术语表为 [rewrite.py](../../src/medops/retrieval/rewrite.py) 中的 `Glossary`（`version`、`entries[term, synonyms, kind]`，norm-v1 已规范化），JSON 文件由工具生成，禁止手改；`version` 形如 `glossary-<YYYYMMDD>-<sha256 前 12 位>`（对 entries 的 canonical JSON 取哈希），任一条目变化即新版本；每条 Trace 记录实际使用的 `glossary_version`（INV-HAR-05）。
2. **来源（按优先级）**：
   - **TFDA 藥品許可證開放資料**（data.fda.gov.tw，「政府資料開放授權條款－第1版」，与 CC BY 4.0 相容；须署名"衛生福利部食品藥物管理署"）：字段 中文品名 → 英文品名、主成分（通用名）；提供繁体商品名 ↔ 英文通用名映射。快照下载日期、URL 与 SHA-256 记录在术语表元数据中。
   - **语料内定义的缩写**：ICH E2A/E2F/E6(R3)/E8(R1)、GVP 模块、FDA 指南、MedDRA 指南等语料文档自身的定义/缩写表（如 ICSR、DSUR、PSUR、SAE、ADR、PRAC、IND）。每条记录 `source_hash` 与页码，并以规范化页文本逐字核对；许可随语料文档的 ADR-0003 准入状态。
   - **DrugBank Open Data 词汇表**（CC0 1.0）：英文通用名与同义词。下载需注册账号，由决策人自行下载后交付；在此之前不纳入。
3. **排除**：MedDRA 词典（受许可限制，仅可引用语料中的指南文本）、WHO INN 列表（使用条款不明确）、《中国药典》名录（版权）、NMPA 数据库抓取（条款不明）。
4. **初始范围**：只收录出现在当前语料（16 份文档）中的药品名与其中定义的缩写，条目数以百计；全量 TFDA 索引（数万条）需先把改写器的匹配改为自动机（Aho-Corasick）再纳入，另行预登记。
5. **更新方式**：重新运行构建工具（输入快照固定、输出可复现）；新版本经离线评测（探针 v2 改写前后召回对比，INV-EVAL-02）后才可进入生产配置；旧版本文件保留以供回放。

## 批准边界

- 术语表只用于查询改写（追加同义词），不改变分词器词典（`dictionary_version`，M1-12）；分词词典若采用同一来源，另行记录版本。
- 不包含任何需要付费或注册许可的词典内容。
