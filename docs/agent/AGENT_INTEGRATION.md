## 2. 可重复执行

固定清单：[AGENT-07-integration-v1.json](../../evals/agent/development/AGENT-07-integration-v1.json)。需要显式测试管理员 DSN，有建删临时数据库权限；测试仅创建并清理自身 `medops_test_*` 数据库及测试登录角色。不要把凭据写进命令、报告或提交。

```sh
# 事先在本地安全设置 MEDOPS_TEST_ADMIN_URL；不回退读取 .env。
PYTHONPATH=src:. venv/bin/python scripts/agent_integration_check.py \
  --run --output .local/agent07/report.json
```

该入口固定选择测试、强制依赖存在、禁用外部 pytest 自动插件、清除已知供应商密钥。它不会启动真实模型客户端。失败、跳过、缺失、实例数减少、重复结果及非零 pytest 退出都不能通过。JSON只含测试身份、状态及摘要，不导出叙述、证据、错误消息或凭据。`--run`另在同目录保留0600权限的原始pytest日志及JUnit用于排障；它们可能含合成正文，留在本地，不提交或上传。

CI的全量 pytest 另存临时 JUnit，随后复用同一结果检查清单，避免重复跑整套数据库测试：

```sh
venv/bin/python scripts/agent_integration_check.py \
  --junit /tmp/medy-check.xml --output .local/agent07/ci-report.json
```

`--junit`只核对输入报告，不认证报告来源或实际执行时间。报告内文件摘要说明检查时的源码；真正的执行绑定需要本轮记录的固定 Git SHA、CI运行及源码摘要，不能拿任意旧XML证明当前源码通过。完整仓库门禁仍独立必需。

## 4. 发现与修复：规划输入冗余

原规划输入每轮复制完整 EvidenceView，包括 `evidence_text_sha256/source_sha256/char_start/char_end`。模型不能使用这些字段扩大权限；它们重复进入后续请求的保守预估，可能使空检索补救在最终核验保护之外无法准入。

现在规划视图只投影 `handle/citation/text/truncated`。正文、数字、否定、适用条件、来源身份和截断提示不变；完整 EvidenceView、证据哈希/区间、句柄绑定及授权检查仍在服务端持久状态中。每个证据省去200多字节；不对正文做裁剪。

规划格式明确为 `pv-planner-v2+evidence-projection`。摘要绑定SYSTEM、格式与投影字段清单；SYSTEM指令原字节保持。旧规划条件的恢复不能悄悄使用新版投影，现有条件校验会拒绝；历史受限审计另保留。没有修改已发布策略指针、默认模型、单次额度、公共API Schema或正式数据库。

## 5. 必须披露的限制

- 12,000 Token不保证走满8步。长输入、最终核验预留及工具原三次尝试包络可能在供应商前拒绝。完整材料可由规划回复直接整理逐字quote再终检；另保留实际提取工具预算拒绝反例，不能据此承诺真实模型会选到可完成路径。
- 正常中文场景的两条独立逐字规则各自引用，原引用规则可直接验证；联合语义组还由独立的真实持久终态测试核验。未放宽语义核验规则或强制每次调用模型裁判。
- fake语义判词只证明正/反判词经过门禁后的行为。AGENT-08仍须明确样本、轮数、模型/profile、预算和停止条件授权，并测真实路径、完成率及成本。
- 无公开Agent收费启动接口、完整S4多轮、部署、独立人工或盲测通过声明。本机共享PG间歇失败仍归DEPLOY-02；不能用干净CI替本机环境宣布修好。
