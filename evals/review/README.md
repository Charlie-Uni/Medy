## 4. 完成一项时应记录什么

1. 修改前后 query、gold、文档/页锚点及理由；将标注修订与系统修复分开。
2. 检查者真实身份、时间、所做检查与原文依据；单人复查不登记为第二独立人工。
3. 新数据版本、映射版本、文件哈希、机械检查输出；旧冻结目录保持不变。
4. 新运行的策略/模型/语料/权限版本、原始结果路径和评分规则；不覆盖旧结论。
5. 无法判断的条件与下一步。待定不能填成通过，未映射证据不能从分母移除。
