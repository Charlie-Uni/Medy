## 4. 第二人工逐题怎么做

复核者应未参与对应原始标注；可以是同一项目的其他人，不要求外部机构。同一个人换账号、晚几天重看，或另一模型复核，均不能记成第二个人。建议具备中英文原文阅读能力；医学或法规含义不确定时记“待定”，交给有相应经验者处理。

逐题提供：问题、文件标题和版本、原页及邻近上下文、gold/key、证据组、标签；安全题另提供权限身份、攻击设置和预期行为。先阅读问题与原文形成自己的判断，再看已有标注，是减少被既有答案影响的建议做法，不另设新门槛。

| 核对点 | 具体动作 |
| --- | --- |
| 问题与来源 | 指定哪个文件、产品、版本？问的是该文件内容，还是另一文件对它的引用？文字有无歧义或错误前提？ |
| 原文支持 | 标准证据能否回答问题？数字、单位、否定、may/must、条件、人群和时限是否一致？查看上下文，不能只读短 key |
| 覆盖与分组 | 是否漏掉必需信息？多组是缺一不可，还是同义替代？是否将可选补充也强制列为必需？ |
| 定位与标签 | key 是否定位了正确条款，截取是否保留限定条件，风险标签是否合理？哈希/偏移/唯一性由工具检查 |
| 孪生与无答案 | 中英文是否等义？无答案应核对指定范围与文档上下文，不能仅凭工具未检索到就认定不存在 |
| 安全预期 | 该案例按项目规则应作答、纠正、拒答还是升级？权限与版本前提是否成立？错误数字的否定性纠正不能误判为肯定 |

每条填“通过 / 有异议 / 待定”，并保留复核者、日期、问题所在字段、原页依据和修改建议。“待定”不计通过。存在分歧时保留两方意见，形成明确裁决后再变更数据；新内容需更新输入绑定及相关复核，旧样本与运行保留。

建议先做本次 19 条，重点看 ms-0241/0242 的第三组证据是否真有必要、ms-0298 两种例外是否完整且被正确区分，再按已分派的风险题和抽样题继续。这只是工作安排，不将 19 条等同于完成 536 条。
