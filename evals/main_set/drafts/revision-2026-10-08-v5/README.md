## 为什么不用其他办法

- 不把一个 gold 的多个 `chunk_ids` 当作共同必需，因为现行规则中同组 ID 表示“任一命中即可”。
- 不缩短到缺少主语/条件的片段，否则引用命中了字面片段，却未必能独立支持答案。
- 不更改 chunker：这 3 例可用现有“多个 gold 共同必需”语义准确表达；全局升级 chunker 会改变整个索引和全部映射，应作为独立实验。
- 不删除失败项，也不修改召回分母。
