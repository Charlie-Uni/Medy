# 独立盲测集准备（阶段 1）

日期：2026-10-08。**状态：准备资料与方案，尚无冻结盲测题。**原主集已经用于调优；本次新增 ms-0525 也已被实现方看到，属于回归用途。

## 1. 已准备的真实资料

[family_inventory_2026-10-08.json](family_inventory_2026-10-08.json) 记录 corpus 的 339 份文档与当前数据库家族：333 active、3 个 corpus 条目未进入数据库，其余 3 条为其他状态。未入库的三份在记录 98 已因 PDF Launch、JavaScript、嵌入文件拒收，不能视为索引遗漏或盲测可用来源。

其中 258 份 active 文档的数据库家族没有在所扫描的主集 gold/无答案范围和安全集显式字段中出现。**这不证明 258 份都未暴露，也不证明彼此独立**：尚未穷尽历史实验、检索证据、译本、转载和近重复内容。本清单因此将 `blind_holdout_eligible` 留为 null。

[related_family_examples.json](related_family_examples.json) 列三组必须进一步合并检查的例子：

- ICH E2D 旧版与 E2D(R1) 新版。
- ICH E6(R3)、FDA E6(R3) 载体及 Annex 2。
- glimepiride 的不同品牌仿单。

数据库 `family_id` 管理版本链，不能单独承担防数据泄漏的语义分组。应在其基础上合并同一产品/成分的等价仿单、原版/译本/转载、指南与直接衍生材料；有争议时保守同组或暂不选取。

## 2. 建议的第一批新题设计

建议先准备 **60 道诊断用新题**：MA/PV/CO 各 20，至少 12 个经核实的独立家族，各部门至少 4 家族，每家族不超过 5 题。这个样本量是试验设计提议，不增加或替代基线门禁；单个小切片不能据此宣称总体达标。

覆盖指定来源、合法等价来源、共同必需证据、数字/否定/时间、无答案和容易误拒答的正常题。语言按来源与 query 分开统计，中英文孪生始终同组；一个原问题与其改写不能算两个独立样本。无答案必须相对冻结的语料/权限/日期检查。

分组完成后再按部门及风险分层抽家族；保存种子、完整候选池、排除理由和分组映射。候选看到题目之前固定题目、gold、rubric、版本、hash 和停止条件。检索库可以含被测公开文档，但开发/调参不得使用该家族的测试问答或等价派生题。

## 3. 保管与防污染

1. 指定独立出题/保管人或受隔离的出题流程；优化实现者只接触分组规则、输入哈希与聚合结果。当前 Codex 已参与旧题调优，不能自己看完新题再称对自己盲测。
2. query/gold/逐题判词放在保管方控制的位置，公开开发清单只登记版本、数量与哈希；不依靠“在同一仓库换个目录名”实现隔离。
3. 测试通过受控 runner 执行，限制日志与 Langfuse payload 对优化者的可见范围；评测人员可以核查完整 trace。先设计访问边界再开启正文采集。
4. 第一次评测前预登记候选与指标。看到失败题后用于修复，该题移入回归集，并记录暴露事件；下一次泛化验证换新题。
5. 输出 Recall/Hit、语义支持、答案完整性、误拒答、系统失败、成本与 P95；记录家族数，使用适当的按家族统计，不将重复运行当独立问题。

## 4. 人工点与完成条件

需要确认出题/保管安排和家族等价关系；这些是独立性与领域判断，机械哈希不能代替。本轮没有安排独立人、生成盲测问答或宣布完成。

完成后应有：核定家族映射、暴露账本、隔离存储、真实复核者、封存的题/标注与 rubric、能验证泄漏边界的测试，以及固定候选的首次盲测记录。全部证据齐全再把阶段表中的“盲测准备”改成“盲测集已建立”。
